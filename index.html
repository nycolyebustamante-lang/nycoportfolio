MODE DETAILS

CAPSTONE SPECIFICATION

LATRANSCO QR-Based Cashless Fare Payment System

Project Context: In Cebu City, public jeepneys operated by transport cooperatives such as LATRANSCO face recurring fare collection friction: drivers juggling cash while steering, dispute over change calculation, and lack of digitised passenger volume records.

Key System Objectives:
  • Automated Route Matrix: Dynamically computes passenger fare based on origin station, destination pickup, and discounted categories (students, senior citizens, PWD).
  • Cryptographic Dynamic QR: Ticket expiration timestamps to prevent screenshot reuse or double redemption.
  • Offline Resilient Logging: Sync mechanism when vehicles operate along low-cellular connectivity pockets.
  • Driver Head-Up UI: High-contrast, minimal audio-visual chime indicator so drivers can acknowledge verified payments without taking eyes off Cebu traffic.
Academic Note: This project is currently in the conceptual prototype and system specification phase as an academic requirement for the Bachelor of Science in Information Technology program.
